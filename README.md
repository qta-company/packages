# QTA packages

apt and yum repository of the [QTA agent](https://github.com/qta-company/qta-agent),
served at https://qta-company.github.io/packages. Generated by `scripts/publish-packages.sh` in the QTA client
repository: do not edit by hand, the next publish overwrites it.

Latest published version: 1.0.0. Signing key fingerprint: `1B6EF9C3EF433393DC3486E6DCE37D4C903E68A0`.

## Debian, Ubuntu

```bash
curl -fsSL https://qta-company.github.io/packages/debian/public.key | sudo gpg --dearmor -o /usr/share/keyrings/qta-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/qta-archive-keyring.gpg] https://qta-company.github.io/packages/debian stable main" | sudo tee /etc/apt/sources.list.d/qta.list
sudo apt-get update
sudo apt-get install qta        # and qta-ui for the desktop app
```

## Fedora, RHEL, Rocky, Alma

```bash
sudo curl -fsSL -o /etc/yum.repos.d/qta.repo https://qta-company.github.io/packages/yum/qta.repo
sudo dnf install qta            # and qta-ui for the desktop app
```

Or let the install script pick: `curl -fsSL https://github.com/qta-company/qta-agent/releases/latest/download/install.sh | sh`.
